# Poker — техасский холдем в консоли

![C++](https://img.shields.io/badge/C++-17-00599C?logo=cplusplus&logoColor=white)
![CMake](https://img.shields.io/badge/CMake-3.16+-064F8C?logo=cmake&logoColor=white)

Консольная игра в техасский холдем один на один: раздача карт, торговля,
определение комбинаций и победителя. Учебный проект первого курса
(МГТУ им. Н. Э. Баумана, ИУ5-14Б, вариант 16, 2024).

## Сборка и запуск

```bash
cmake -B build
cmake --build build
./build/poker
```

Без CMake:

```bash
clang++ -std=c++17 -I. main.cpp bet.cpp win.cpp "game table.cpp" -o poker
./poker
```

## Структура

| Файл | Что внутри |
|---|---|
| `main.cpp` | игровой цикл: раздачи, круги торговли, банк |
| `game table.cpp` | колода, раздача игрокам, флоп, тёрн и ривер |
| `bet.cpp` | ставки: повышение, пас, олл-ин |
| `win.cpp` | комбинации, выбор лучшей руки и победителя |
| `page header.h` | структуры карт, рук и игроков |
| `experimental/ai_bet.cpp` | черновик ставок ИИ, в сборку не входит |

# Техническое задание (ТЗ) Евсеева Д.М. ИУ5-14Б Вариант 16 “ИИ для покера”
## Цель проекта:
Разработка программы на языке программирования C++, которая оценивает вероятность победы в покере на основе имеющихся карт и принимает решение о поднятии ставки, согласно расчетам.
## Описание концепции игры: 
В игре используются правила техасского холдема, где у каждого игрока (ИИ и человека) на руках по две карты, а на столе может быть от трех до пяти общих карт.
Описание функциональности:
- 	Определение комбинации карт:
Программа должна способствовать выявлению комбинаций карт у каждого игрока.
Должна уметь распознавать основные комбинации: пара, две пары, тройка, стрит, флеш, фул-хаус, каре, стрит-флеш, роял-флеш.
- 	Оценка вероятности победы:
На основе комбинаций карт у игрока и общих карт на столе, программа должна расчитывать вероятность победы.
Расчеты могут быть основаны на статистических данных или математических моделях.
- 	Принятие решений по ставкам:
На основе вероятности победы, программа должна определять, следует ли увеличивать ставку (поднимать), поддерживать текущую ставку или сбросить карты (пасовать).
Решение должно приниматься с учетом текущего состояния игры, предыдущих действий оппонентов и размера текущей ставки.
- 	Интерфейс пользователя:
Программа должна иметь простой текстовый или графический интерфейс для взаимодействия с пользователем.
Вывод информации о текущей руке, вероятности победы и решениях по ставкам.

## Описание систем:
- 	Система раздач карт игрокам и на стол:
Программа должна раздавать по 2 карты игрокам, потом 3 на стол (флоп), потом еще одна (тёрн), и последняя (ривер)
- 	Система выбора ставок:
Программа получает от пользователя или ИИ один из вариантов ставки после каждого хода, пока ставки не будут равны или ктото не скажет пасс.#
- 	Система выбора победителя: 
Программа получает всевозможные вариации рук для каждого из игроков, для каждого из них выбирает лучшую и потом сравнивает 2 лучшие руки, для выявления победителя
- 	Система передачи и обработки информации ИИ:
ИИ передается данные о картах на руке, на столе и в колоде, после этого он высчитывает вероятность победы, и в зависимости от него делает ставки.
